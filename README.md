# Bố cục trang responsive (RWD)

Bài tập dựng bố cục tạp chí bằng các khối HTML và CSS. Trang gồm header, nội dung nổi bật, danh sách câu chuyện, sidebar và footer; Grid chuyển từ hai cột sang một cột trên màn hình nhỏ.

## Chạy thử

Mở `index.html` trong trình duyệt rồi thay đổi chiều rộng cửa sổ. Ở kích thước mobile, phần nội dung nổi bật, danh sách bài viết và sidebar xếp dọc để tránh tràn ngang.
